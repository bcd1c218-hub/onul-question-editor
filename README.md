# 오늘의 질문 편집실

고려 단원(사회 5-2) "AI 활용 탐구 질문 중심 수업"용 웹앱입니다. 원고 편집실과 같은 구조
(Vite + React + Firebase + Vercel 서버 함수)로 만들었고, 학생은 로그인 없이 이름과 모둠만 넣고 씁니다.

- **질문 다듬기 (4차시)**: 학생이 쓴 탐구 질문을 AI가 질문 사다리(사실적·개념적·논쟁적·실제적)와
  연구회 4조건으로 살펴보고 **되묻기 1개**만 합니다. 질문을 대신 써 주지 않습니다.
  학생은 고쳐 쓰기를 반복한 뒤 "받아들인 것 / 받아들이지 않은 것과 이유"를 남깁니다.
- **기자회견 (6차시)**: 모둠이 폰 한 대로 고려 사람 7명 중 한 명을 인터뷰합니다.
  인물은 교과서(40~57쪽) 내용만으로 설정되어 있고, 모르는 것은 모른다고 답하게 되어 있습니다.
- **교사 화면**: 주소 뒤에 `?teacher=1` → 학생별 질문 변화, 모둠별 인터뷰 기록을
  보고 CSV로 내려받을 수 있습니다.

## 폴더 구조

```
api/question-coach.js   질문 다듬기 AI 호출 (서버)
api/interview.js        기자회견 AI 호출 (서버)
lib/prompts.js          질문 다듬기 프롬프트 (핵심 질문, 사다리, 4조건)
lib/personas.js         기자회견 인물 7명의 교과서 사실 목록  ← 인물 내용을 고칠 때 여기
lib/anthropic.js        Claude API 호출 (원고 편집실과 같은 모델)
src/components/         학생 화면, 질문 다듬기, 기자회견, 교사 화면
src/data/               사다리·조건 이름, 인물 카드(학생 화면용)
firestore.rules         원고 편집실 + 질문 편집실 규칙 합본
```

## 배포 순서 (원고 편집실을 배포해 본 그대로)

1. **Firebase**: 원고 편집실과 **같은 Firebase 프로젝트**를 그대로 씁니다.
   Firestore → 규칙 탭에 이 폴더의 `firestore.rules` 전체를 붙여넣고 "게시".
   (기존 원고 편집실 규칙도 들어 있으니 그대로 덮어써도 됩니다.)
2. **GitHub**: 새 저장소(예: `onul-question-editor`)를 만들고 이 폴더를 올립니다.
3. **Vercel**: Add New → Project → 새 저장소 선택 → Environment Variables에
   원고 편집실 프로젝트와 **같은 값**을 그대로 넣습니다.
   (Vercel의 원고 편집실 프로젝트 → Settings → Environment Variables에서 복사)
   - `VITE_FIREBASE_...` 6개, `ANTHROPIC_API_KEY`
4. Deploy → `https://새이름.vercel.app` 이 학생용, 뒤에 `?teacher=1`이 교사용입니다.

## 수업 전 점검

- 교사가 먼저 질문 다듬기에 연습 질문 10~15개를 넣어 보고, AI가 **질문을 대신 써 주지 않는지**,
  사다리 칸 판단이 납득되는지 확인하세요.
- 기자회견은 7명 모두에게 질문 3개씩 해 보고, 교과서와 다른 말을 하면 `lib/personas.js`의 사실 목록을
  보완하세요.
- 학생 폰 1~2대로 실제 접속, 새로고침 후 이어 하기를 확인하세요.

## 알려진 제한사항

- 원고 편집실과 마찬가지로 Firestore 규칙이 로그인 없이 열려 있습니다. 학급 활동 수준의 자료만 다루세요.
- 학생 이름만으로 구분하므로 같은 이름이 있으면 번호를 붙여 쓰게 하세요.

## 수업 전 점검용 연습 질문 (질문 다듬기)

아래 질문을 넣어 보고, ① 질문을 대신 써 주지 않는지 ② 사다리 칸 판단이 납득되는지 ③ 장난 질문을 걸러 내는지 확인하세요.

1. 벽란도는 어디에 있었을까?
2. 고려청자는 예뻐요?
3. 노비는 왜 사고팔렸을까?
4. 고려 여자들은 재산을 받았을까?
5. 왜 아들과 딸에게 재산을 똑같이 나눠 주었을까?
6. 평량이 뇌물을 주고 양인이 된 것은 옳은 일이었을까?
7. 팔만대장경은 몇 장일까?
8. 고려 사람들은 왜 부처의 힘으로 몽골을 막으려 했을까?
9. 서희는 어떻게 싸우지 않고 땅을 얻었을까?
10. 과거 시험이 생기면서 고려 사회는 어떻게 달라졌을까?
11. 오늘날 우리가 고려의 교류에서 배울 점은 무엇일까?
12. 절에서 왜 장사를 했을까?
13. 선생님 몇 살이에요?  ← 관계없는 질문
14. 고려 사람도 게임 했어요?  ← 장난 질문
15. 신분이 다르면 먹는 음식도 달랐을까?

## 기자회견 점검 질문

각 인물에게 ① 교과서에 있는 사실 질문 ② 교과서에 없는 질문(예: "하루에 몇 시에 일어나요?") ③ 미래 질문(예: 상인에게 "몽골이 쳐들어오면 어떻게 할 거예요?")을 해 보고,
③에는 "아직 일어나지 않은 일이라 모르겠다"고 답하는지 확인하세요.
